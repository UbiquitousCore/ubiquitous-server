# Ubiquitous.World

Maps and what is in them: `InstanceWorldState` (a dungeon copy's
population and id counter), `WorldSessionState` (one session's
position and movement validation), `PlayerMovementLimits`, `NavigationMesh` / `WalkableGroundSource`,
`TerrainHeightmap`, `SimulationTiming` and `TileGrid`. No transport, game
rules or persistence. Tests: `tests/world`.
