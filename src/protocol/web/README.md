# Ubiquitous.Protocol.Web

The WebSocket JSON contract with `ubiquitous-client`: `WebMessageEnvelope`
(`type`, `sequence`, `payload`), the message names in `WebMessageTypes*.cs`,
their payload records in `WebPayloads*.cs`, and the named wire codes in
`WireCodes.cs` (see `docs/architecture/wire-codes.md`). No sockets or game
rules. Tests: `tests/web-protocol`.
